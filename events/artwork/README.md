# Events image pack

Keep this folder separately from the deployed app. The WebP files are optimised for upload; `originals/` contains the full PNG masters. Prompts and provenance are in `ASSETS.md`.

1. In the Events back office, open **Files & media → Upload images**. Upload the three WebP files to the Events library. Alternatively, use Upload beside an image selector.
2. Open **Settings → Theme & branding → Website imagery**. Choose **Library** beside each field and save settings.
3. Open each event, choose **Edit event → Event artwork → Library**, select the image and save the event.

| File | Suggested selection |
| --- | --- |
| events-theatre.webp | Homepage hero; After Hours / Live event artwork |
| events-gallery.webp | Ideas in the Open event artwork |
| events-supper.webp | Editorial image; Sunday Table event artwork |

These choices save the URLs returned by Cloudgate's media server. The public site, event cards, detail pages and organiser panels use those saved selections. The generated photos are not bundled into the deployed site. Until an image is selected, the site uses a neutral background or placeholder illustration.

Use **Use entire image** when uploading if you want to retain the original composition. You may reuse the same uploaded file in more than one selector. Images selected for branding or an event are marked as in use in the media library.
